## Fread Peak Velocity Information
Information here was originally developed by LMRFC and has been reformatted to fit here.

The Fread velocity equation was provided by Danny Fread at a FLDWAV workshop held at OHD in November 2006. 

Flood wave velocity associated with a dam breach is computed as follows:

**c = (0.005 / n) * H^(2/3) * S^(1/2)**

**Where:**
* **c** = Wave Speed (mi/hr)
* **n** = Manning's n
* **H** = Breach Head (ft) - defined as Depth of Water at time of Breaching
* **S** = Channel Bottom Slope (ft/mi)

---

### Suggested Manning's "n" Values

A brief sample of possible Manning's "n" values follow, extracted from *Chow, V.T., "Open Channel Hydraulics", McGraw-Hill, 1959*:

#### Main Channels
| Description | n Value |
| :--- | :--- |
| Clean, straight channel with no rifts or pools | 0.030 |
| Clean, winding, some pools and shoals | 0.040 |
| Clean, winding, with stones | 0.050 |
| Sluggish reaches, weedy, deep pools | 0.070 |
| Very weedy reaches, deep pools, floodways with heavy timber and underbrush | 0.100 |

#### Flood Plains
| Description | n Value |
| :--- | :--- |
| Pasture, no brush | 0.030 |
| Cultivated areas (no crops) | 0.030 |
| Cultivated areas (mature field crops) | 0.040 |
| Scattered brush with heavy weeds | 0.050 |
| Light brush and trees (winter) | 0.050 |
| Light brush and trees (summer) | 0.060 |
| Medium to dense brush (winter) | 0.070 |
| Medium to dense brush (summer) | 0.100 |

#### Forest
| Description | n Value |
| :--- | :--- |
| Dense willows, summer | 0.150 |
| Cleared land with tree stumps, no sprouts | 0.040 |
| Cleared land with tree stumps, heavy sprouts | 0.060 |
| Heavy timber stand, few downed trees, flood stage below branches | 0.100 |
| Heavy timber stand, few downed trees, flood stage reaching branches | 0.120 |

---

*Additional information can be found in the document: "Guide for selecting Manning's Roughness Coefficients for Natural Channels and Flood Plains", by Arcement, G.J.Jr and Schneider, V.R., USGS Water-Supply Paper 2339.*
